# 📖 Owntemp ইউজার ম্যানুয়াল (বাংলা)

> **সংস্করণ:** `v2.5.3`  
> **প্রোডাক্ট ক্যাটাগরি:** আজীবন ফ্রি ডিসপোজেবল টেম্পোরারি ইমেইল ও রিয়েল-টাইম ওটিপি ডিটেকশন প্ল্যাটফর্ম

## 🎯 ১. পরিচিতি ও মূল সুবিধাসমূহ
Owntemp হলো একটি পূর্ণাঙ্গ বাণিজ্যিক মানের টেম্প মেইল ইঞ্জিন। সাধারণ ডিসপোজেবল ইমেইলের মতো এটি কিছুক্ষণ পর মুছে যায় না; বরং প্রয়োজনবোধে আজীবন সংরক্ষণ (Lifetime Pin-Lock) করার অসাধারণ নিরাপত্তা প্রদান করে।

### প্রধান প্রধান সুবিধাসমূহ:
1. **১-ক্লিকে ইনস্ট্যান্ট অ্যাড্রেস:** কোনো রেজিস্ট্রেশন ছাড়াই সাথে সাথে ইউনিক ইমেইল ঠিকানা তৈরি।
2. **৫০,০০০+ মেগা ডোমেইন ডিরেক্টরি:** বিশ্বের বৃহত্তম কালেকশন থেকে যেকোনো ক্যাটাগরির ডোমেইন নির্বাচন।
3. **আজীবন পিন-লক (Lifetime PIN Lock):** ৪ ডিজিটের গোপন পিন দিয়ে আপনার ইনবক্স লক করুন; কেউ কখনোই আপনার ইমেইল পড়তে বা ডিলিট করতে পারবে না।
4. **স্মার্ট ওটিপি এক্সট্র্যাক্টর:** নতুন ইমেইল আসার সাথে সাথে স্বয়ংক্রিয়ভাবে ওটিপি ডিটেক্ট হয়, ভয়েস পড়ে শোনায় এবং ১-ক্লিকে কপি করা যায়।
5. **ডিসপোজেবল রিপ্লাই ইঞ্জিন:** সক্রিয় টেম্প মেইল থেকে সরাসরি প্রেরককে ইমেইল উত্তর (Reply) পাঠানো।
6. **টেলিগ্রাম তাৎক্ষণিক নোটিফিকেশন:** নতুন ইমেইল ও ওটিপি আসার সাথে সাথে আপনার টেলিগ্রাম বটের মাধ্যমে মোবাইলে নোটিফিকেশন।
7. **PWA অফলাইন সুবিধা:** অ্যান্ড্রয়েড বা পিসিতে সরাসরি নেটিভ অ্যাপ হিসেবে ইনস্টল করার ব্যবস্থা।

## 🚀 ২. ধাপে ধাপে ব্যবহারের নির্দেশিকা

### ধাপ ১: সক্রিয় ইমেইল ঠিকানা কপি করা
- ওয়েবসাইটের ওপরের ব্যানার থেকে বড় করে দেখানো ইমেইল ঠিকানার পাশে থাকা **"কপি করুন"** বাটনে ক্লিক করুন (অথবা কীবোর্ডের **`C`** বাটন চাপুন)।

### ধাপ ২: যেকোনো সাইটে রেজিস্ট্রেশন করা
- Facebook, Google, Twitter, Netflix বা যেকোনো অনলাইন সেবায় অ্যাকাউন্ট খোলার সময় এই কপি করা ইমেইলটি ব্যবহার করুন।

### ধাপ ৩: ওটিপি কোড গ্রহণ করা
- ওয়েবসাইট থেকে কোড পাঠানোর সাথে সাথে Owntemp স্ক্রিনে বেলের শব্দ বাজবে।
- স্ক্রিনের নিচে ফ্লোটিং ওটিপি কার্ড ভেসে উঠবে।
- **"কপি ওটিপি"** বাটনে ক্লিক করে কোড কপি করে সাইন-আপ সম্পন্ন করুন।

### ধাপ ৪: ইনবক্স আজীবন সুরক্ষিত (লক) করা
- ইনবক্সের পাশে থাকা **"লক করুন"** বাটনে ক্লিক করুন (কীবোর্ড শর্টকাট: **`L`**)।
- ৪ বা ততোধিক ডিজিটের গোপন পিন কোড সেট করুন।
- লক সম্পন্ন হলে এই ইনবক্সটি আজীবন সুরক্ষিত থাকবে এবং ক্রন-জব ক্লিনার কখনোই এটি ডিলিট করবে না।

### ধাপ ৫: ইমেইলের উত্তর পাঠানো (Reply)
- যেকোনো ইমেইল ওপেন করার পর উপরের টুলবার থেকে **"উত্তর দিন" (<Reply />)** বাটনে ক্লিক করুন।
- প্রেরকের ঠিকানায় মেসেজ লিখে **"সেন্ড করুন"** চাপুন।

### ধাপ ৬: সমস্ত মেসেজ ব্যাকআপ নেওয়া (JSON ও CSV)
- ইনবক্স হেডারে থাকা **"JSON"** বাটনে ক্লিক করলে সমস্ত ইমেইল ফাইল আকারে ডাউনলোড হবে (শর্টকাট: **`E`**)।
- **"CSV"** বাটনে ক্লিক করলে সমস্ত ইমেইল ও ওটিপি এক্সেল স্প্রেডশিট আকারে ডাউনলোড হবে (শর্টকাট: **`V`**)।

## ⌨️ ৩. কীবোর্ড শর্টকাট গাইড (পাওয়ার-ইউজারদের জন্য)

| কীবোর্ড কী | কাজের বিবরণ |
| :---: | :--- |
| **`C`** | সক্রিয় ইমেইল ঠিকানা ১-ক্লিকে কপি |
| **`R`** | ইনবক্সের সমস্ত নতুন ইমেইল রিফ্রেশ |
| **`N`** | নতুন র‍্যান্ডম ইমেইল ঠিকানা তৈরি |
| **`L`** | আজীবন পিন লক/আনলক মডাল খোলা |
| **`S`** | ইমেইল টেস্ট সিমুলেটর চালু |
| **`D`** | ৫০,০০০+ ডোমেইন ডিরেক্টরি ওপেন |
| **`E`** | JSON ব্যাকআপ ফাইল ডাউনলোড |
| **`V`** | CSV এক্সেল স্প্রেডশিট ডাউনলোড |
| **`?`** | কীবোর্ড শর্টকাট চিটশিট HUD ওপেন |
| **`Esc`** | যেকোনো খোলা মডাল বা ইমেইল ভিউ বন্ধ করা |

## 🛠️ ৪. ক্লাউডফ্লেয়ার ডোমেইন ইন্টিগ্রেশন (নিজস্ব কাস্টম ডোমেইন)
1. টপবারের **"সেটিংস"** আইকনে ক্লিক করুন।
2. **Cloudflare & API** ট্যাবে যান।
3. আপনার Cloudflare API Token দিন।
4. **"ক্লাউডফ্লেয়ারে থাকা আমার ডোমেইনগুলো খুঁজুন"** বাটনে চাপ দিয়ে আপনার ডোমেইন সিলেক্ট করুন।
5. **"অটোমেটিক ক্লাউডফ্লেয়ার সেটআপ করুন"** বাটনে ক্লিক করলেই এমএক্স রেকর্ড (MX Records) এবং ইমেইল ওয়ার্কার্স স্বয়ংক্রিয়ভাবে সক্রিয় হয়ে যাবে।
6. **"⚡ ডায়াগনস্টিক টেস্ট চালান"** বাটনে ক্লিক করে পুরো পাইপলাইনের স্বাস্থ্য পরীক্ষা করে নিন।

## ❓ সাধারণ প্রশ্নোত্তর (FAQ)

**প্রশ্ন: ইনবক্স লক পিন ভুলে গেলে কী করব?**  
উত্তর: নিরাপত্তার স্বার্থে ক্রিপ্টোগ্রাফিক সুরক্ষা থাকায় সঠিক পিন ছাড়া লক খোলা সম্ভব নয়। ভুল পিন ৫ বার দিলে ১০ মিনিটের কুলডাউন রেট-লিমিট সক্রিয় হয়।

**প্রশ্ন: টেলিগ্রাম এলার্ট কীভাবে সেট করব?**  
উত্তর: সেটিংস মডালের "টেলিগ্রাম" ট্যাবে আপনার বট টোকেন (`Bot Token`) এবং চ্যাট আইডি (`Chat ID`) বসিয়ে টেস্ট এলার্ট বাটনে ক্লিক করুন।
